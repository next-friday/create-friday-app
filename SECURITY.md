# Security policy

## Supported versions

The package is currently unreleased at `0.0.0`. Security fixes apply to the `main` branch.

After the first published release, only the latest published release receives security updates. Earlier releases and prerelease versions are not supported.

## Report a vulnerability

Do not report security vulnerabilities in public GitHub issues.

1. Use [GitHub Private Vulnerability Reporting](https://github.com/next-friday/create-friday-app/security/advisories/new).
2. Or email `security@next-friday.com`.
3. Include reproduction steps, the affected package version or commit, the command you ran, and environment details. Remove secrets and private data.

### Response targets

- **Acknowledgment:** Within 2 business days.
- **Assessment:** Within 5 business days, including severity and impact.
- **Fix and advisory:** For a confirmed critical issue, a patch release and a GitHub Security Advisory.
