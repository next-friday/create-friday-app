# Demand-Driven Configuration

Add or change a setting for an active requirement in that configuration's scope. Prefer the smallest config that satisfies the current contract. Reuse a repeated value when a local name makes it clearer. Remove settings no active path, test, or documented purpose reads.

Make paths, patterns, and ignores match files that exist in the intended project. Compose from shared definitions; keep each pattern in one source of truth.

Verify a setting through the tool's validation or effective-configuration output.
