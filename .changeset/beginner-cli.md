The CLI is easier to start. Pressing Enter at the prompts creates `my-app` from the Next.js stack, each prompt says in a full sentence what the choice gives, and each stack's choice says what the project holds. `--yes`, or `-y`, takes those defaults and asks nothing, with or without a terminal; a name or `--stack` given with it wins. It stops before writing a file when a `my-app` directory with files already exists.
