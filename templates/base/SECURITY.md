# Security Policy

## Supported versions

Only the latest commit on the `main` branch receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through **Security → Report a vulnerability** in this repository. Describe the issue, the affected files or versions, and steps to reproduce it.

Do not open a public issue, pull request, or discussion for a vulnerability.

## What to expect

A maintainer acknowledges the report, confirms or rejects the finding, and coordinates a fix and disclosure date with you.
