The CLI's command is renamed from `create-friday-app` to `create-next-friday-app`, matching the repository name; `create-friday-app` is removed. `pnpm create @next-friday/app`, `npm init @next-friday/app`, and `npx @next-friday/create-app` work as before. If you installed the package globally or call the command by name in a script, run `create-next-friday-app` instead.
