## Proposed outcome

- The shell gate is small, in the root and in every template: it blocks skipping Git hooks and, in Cursor only, a shell redirect or `tee` whose target is a protected path inside this checkout. Claude Code already checks those targets against the `Edit` deny rules ("as if Claude wrote or read that file directly", [Claude Code: Permissions](https://code.claude.com/docs/en/permissions)); Cursor has no such rule for shell commands, so the gate gives Cursor the same guard, as `intent/multi-agent-support/intent.md` promises. It blocks nothing outside the checkout, and its test covers only these cases.
- The rules that load in every session are short, in the root and in every template: overlapping rules are merged, and only rules about this repository's own conventions remain.
- A correction to rules, hooks, or agent settings goes into the pull request where it is found, and code owners approve it there; the separate-issue rule is removed.
