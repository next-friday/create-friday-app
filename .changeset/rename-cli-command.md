The CLI's command `create-friday-app` is now `next-friday-create-app`, matching the repository name. `pnpm create @next-friday/app`, `npm init @next-friday/app`, and `npx @next-friday/create-app` work as before. If you installed the package globally or call the command by name in a script, run `next-friday-create-app` instead.
